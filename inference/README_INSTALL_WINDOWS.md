# NileTTS 4h — حزمة التوليد المحلية على Windows (CPU فقط)

دليل تركيب وتشغيل خطوة بخطوة — لا يحتاج كارت شاشة، ولا أي اتصال بـKaggle
بعد التركيب، ولا ينزّل أي شيء أثناء التشغيل.

---

## محتويات الحزمة

| المجلد/الملف | الوظيفة |
|---|---|
| `infer.py` | سكريبت التوليد المستقل (نص ← ملف WAV) |
| `webapp.py` | خادم واجهة الويب (نفس التوليد من صفحة في المتصفح) |
| `web/index.html` | صفحة الواجهة العربية (تعمل بلا إنترنت) |
| `requirements.txt` | المكتبات بنسخ مضبوطة (6 مكتبات فقط) |
| `run.bat` | مشغّل سطر الأوامر السريع لنظام Windows |
| `run_web.bat` | مشغّل واجهة الويب السريع |
| `checkpoints/` | **ضع هنا ملف الـcheckpoint الخاص بك** (مثل `states_79590.pth`) |
| `lib/mixer_repo/` | تعريف نموذج MixerTTS (كود البنية كما في التدريب) |
| `lib/tts_arabic/` | مكتبة الترميز + المُشكِّل النصي |
| `lib/tts_arabic/data/catt_eo.onnx` | أوزان المُشكِّل catt_eo (مضمّنة — 75MB) |
| `weights/vocos22.onnx` | المُصوِّت الصوتي vocos (مضمّن — 57MB) |
| `samples/test_sentences.txt` | جمل الاختبار المعتمدة من نواة التدريب |
| `samples/example_output.wav` | مخرج مرجعي للتأكد من سلامة التركيب (انظر الخطوة 6) |
| `PATCHES.md` | توثيق التعديلات الجراحية الخمسة على الكود المضمّن |

> الـcheckpoint نفسه (مثل `states_79590.pth`) **غير مضمّن** لأنه موجود
> عندك بالفعل محليًا — انظر الخطوة 3.

---

## المتطلبات قبل البدء

- Windows 10 أو 11 (**64-bit** — الزامي).
- حوالي **1.5 GB** مساحة حرة على القرص (بايثون + المكتبات ≈ 900MB + الحزمة 140MB).
- إنترنت **للتركيب مرة واحدة فقط** (تنزيل بايثون + ~250MB مكتبات).
- لا تحتاج GPU ولا أي أدوات لينكس إطلاقًا.

---

## الخطوة 1 — تركيب بايثون 3.12 (64-bit)

1. افتح المتصفح وادخل على: **https://www.python.org/downloads/**
2. اضغط زر التحميل الأصفر الكبير (سيعطيك أحدث 3.12.x أو 3.13.x —
   إن أعطاك 3.13 فارجع لصفحة Downloads واختر من قائمة "Looking for a
   specific release" إصدار **Python 3.12.10** أو أحدث 3.12.x — نسخة
   Windows installer (64-bit)).
3. شغّل ملف التحميل `python-3.12.x-amd64.exe` وفي أول شاشة:
   - **مهم جدًا:** علّم بالمربع ✅ **"Add python.exe to PATH"**
     (أسفل نافذة المعالج قبل زر Install).
   - اضغط **Install Now** وانتظر حتى تظهر "Setup was successful"
     ثم أغلق النافذة.
4. تأكد من التركيب: اضغط زر Windows + حرف R معًا → اكتب `cmd` →
   اضغط موافق → في النافذة السوداء اكتب:
   ```
   python --version
   ```
   يجب أن يطبع `Python 3.12.x` — لو قال "python is not recognized"
   فأنت نسيت مربع PATH: أعد التركيب ونفّذ التعليمات مرة أخرى.

## الخطوة 2 — فك ضغط الحزمة

1. اضغط بزر الفأرة الأيمن على ملف `NileTTS-4h-Inference.zip` →
   **Extract All...** (استخراج الكل).
2. اختر مسارًا بسيطًا بلا مسافات أو حروف عربية، والمستحسن:
   ```
   C:\NileTTS-4h-Inference
   ```
3. اضغط Extract وانتظر انتهاء الفك (نحو دقيقة — الحزمة 140MB).

## الخطوة 3 — وضع الـcheckpoint الخاص بك

1. من مخرجات نواة التدريب على Kaggle (Output)، كان عندك ملف
   **`states_79590.pth`** محفوظًا محليًا (هو نفسه الذي في مجلد
   `Output\checkpoints` عندك).
2. انسخه والصقه داخل مجلد الحزمة:
   ```
   C:\NileTTS-4h-Inference\checkpoints\states_79590.pth
   ```
   (يمكنك وضع أكثر من ملف `states_*.pth` — السكريبت يختار الأحدث تلقائيًا.)

## الخطوة 4 — تركيب المكتبات (مرة واحدة فقط)

افتح موجه الأوامر: زر Windows + R → اكتب `cmd` → موافق، ثم اكتب الأوامر
التالية بالترتيب (كل سطر ثم Enter):

```
cd /d C:\NileTTS-4h-Inference
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

- الانتظار المتوقع: **3–10 دقائق** حسب سرعة النت (يُنزّل ~250MB:
  نسخة torch الخاصة بـWindows وهي CPU تلقائيًا، فلا تخشَ أي مكونات CUDA).
- انتهى التركيب بنجاح عندما تظهر `Successfully installed ...`.
- **من هذه اللحظة لا تحتاج إنترنت ولا Kaggle إطلاقًا.**

> لو فشل التركيب بسبب الشبكة فقط، جرّب:
> `python -m pip install -r requirements.txt --index-url https://download.pytorch.org/whl/cpu`

## الخطوة 5 — التوليد الأول

في نفس نافذة موجه الأوامر:

```
python infer.py --checkpoint states_79590.pth --text "السلام عليكم يا صديقي" --out out.wav
```

- انتظر ثانيتين إلى ~6 ثوانٍ (حسب سرعة المعالج).
- سيظهر سطر `تم: out.wav ...` — افتح الملف بالمسار
  `C:\NileTTS-4h-Inference\out.wav` واستمع إليه بأي مشغل صوت.
- لو الكتابة بالعربي في موجه الأوامر صعبة/معكوسة عندك، استخدم ملف نص:
  احفظ النص في ملف `input.txt` (بترميز UTF-8 — الافتراضي في Notepad
  الحديث) ثم:
  ```
  python infer.py --text-file input.txt --out out.wav
  ```

### البديل الأسهل — واجهة الويب (موصى بها للمبتدئين)

بدل سطر الأوامر، يمكنك صفحة ويب عربية تكتب فيها النص وتضبط كل
المعاملات (المتحدث ذكر/أنثى، اللهجة، السرعة، التشكيل، تقسيم النص
الطويل تلقائيًا...) وتستمع للناتج مباشرة وتنزّله. التشغيل:

```
python webapp.py
```

- انتظر ظهور سطر `الخادم يعمل الآن ← http://127.0.0.1:8500`
  (بضع ثوانٍ لتحميل النماذج) — **سيفتح المتصفح تلقائيًا** على الصفحة.
- أو انقر نقرًا مزدوجًا ملف `run_web.bat` في مستكشف الملفات.
- كل توليد يُحفظ تلقائيًا في مجلد `web_outputs` بجوار الحزمة.
- لإيقاف الخادم: أغلق نافذة الأوامر أو اضغط `Ctrl+C`.
- الواجهة لا تحتاج أي مكتبات جديدة ولا إنترنت — مسار التوليد فيها
  هو نفسه مسار `infer.py` حرفيًا (تم إثبات تطابق المخرجات بايت-ببايت).

## الخطوة 6 — اختبار التأكد (مقارنة مع مخرج مرجعي)

شغّل الجملة المرجعية نفسها التي وُلّد منها الملف المضمّن
`samples\example_output.wav`:

```
python infer.py --text "إِزَّيْك يَا صَاحِبِي، عَامِل إِيهْ دِلْوَقْتِي؟" --out check.wav --vocalize never --speaker 0
```

ثم قارن بالسمع `check.wav` مع `samples\example_output.wav` — يجب أن
يكونا **نفس الصوت تمامًا** (الاثنان وُلّدا من نفس الـcheckpoint 79590
ونفس الجملة ونفس المتحدث). هذا دليل قاطع أن التركيب سليم على جهازك.
(المقارنة رقميًا لو تحب: تطابق طول الملفين بالبايت تقريبًا يكفي.)

## الاستخدام اليومي — كل الخيارات

```
python infer.py --help
```

| الخيار | القيم | الشرح |
|---|---|---|
| `--checkpoint` | مسار/اسم ملف | افتراضي: أحدث `states_*.pth` في `checkpoints/` |
| `--text` | نص بين علامتي تنصيص | النص مباشرة |
| `--text-file` | مسار ملف | النص من ملف UTF-8 (بديل مريح للعربي في الكونسول) |
| `--out` | مسار | ملف WAV الناتج (افتراضي `out.wav`) |
| `--speaker` | 0 أو 1 | **0 = SPEAKER_01 ذكر** (افتراضي) ، **1 = SPEAKER_02 أنثى** |
| `--dialect` | egy أو msa | egy: الترميز المصري (افتراضي) ، msa: فصحى |
| `--pace` | رقم | سرعة الكلام: 1.0 طبيعي، أقل من 1 أبطأ وأوضح، أكبر أسرع |
| `--vocalize` | auto / always / never | auto: يشكّل النص بـcatt_eo لو غير مشكول (افتراضي)؛ never: يستخدم تشكيلك كما هو |
| `--qaf` | auto / qaf / hamza / g | **نطق القاف** (افتراضي auto = السلوك المعتمد بدون تغيير). `qaf` = فصحى المصطلحات التعليمية (رقم/قسمة/تقريب/قياس/قيمة/قاعدة... → قاف فصحى تقريبية [k] — قائمة مغلقة ليست كل كلمة)؛ `hamza` = فرض الهمزة شاملًا؛ `g` = فرض الجيم [g] شاملًا |
| `--det-vocalize` | — | تفعيل **طبقة التصحيح الجزئي** فوق التشكيل التلقائي (مطفأ افتراضيًا): تصحيح جزئي — أرقام وترقيم وقوائم مغلقة ونهايات فقط، **ليست بديلًا عن تشكيل tashkeel-ai** (تطابق كلمة-بكلمة: 45.2% عينة معزولة · 57.9% عينة متحيزة — رقم ثانوي) |
| `--denoise` | رقم | تنقية الضوضاء بعد التوليد (افتراضي 0.005) |
| `--threads` | رقم | تقييد عدد أنوية المعالج المستخدمة (لو الجهاز ضعيف) |
| `--verbose` | — | تفاصيل تقنية (عدد التوكنز، التوقيتات) |

أمثلة جاهزة:

```
python infer.py --text "دلوقتي هنبدأ الدرس يا عمر." --out dars.wav --speaker 0
python infer.py --text "أنا عايز أعرف إنت عملت إيه النهارده." --out ask.wav --speaker 1 --pace 0.9
python infer.py --text-file magazine_paragraph.txt --out para.wav --speaker 0
python infer.py --text "اَللُّغَةُ الْعَرَبِيَّةُ مِنْ أَكْثَرِ اللُّغَاتِ" --out msa.wav --dialect msa --vocalize never
```

### نصائح مهمة للجودة

1. **النص المشكول أفضل دائمًا**: لو عندك تشكيل يدوي أو من خط التشكيل
   بتاعك، مرّره مع `--vocalize never` — سمعته أعلى من تشكيل catt
   التلقائي (الفصحى الإعرابية).
2. **قسّم النصوص الطويلة**: النموذج تدرّب على جمل ≤ 160 توكن (~15-20
   كلمة). السكريبت يحذّرك لو تجاوزت الحد — قسّم الفقرة لجمل.
3. **الترقيم يُقص تلقائيًا** (فواصل/علامات استفهام/أرقام/إنجليزي):
   هذا مقصود ومطابق لبيانات تدريب النموذج — لا داعي لتنظيف يدوي.

## حل المشكلات الشائعة

| المشكلة | الحل |
|---|---|
| `'python' is not recognized...` | بايثون غير مضاف لـPATH — أعد التركيب مع تعليم المربع (الخطوة 1.3) |
| `لم أجد الـcheckpoint` | تأكد أن الملف موجود في `checkpoints\` وأن اسمه `states_*.pth` أو مرّر `--checkpoint` بمسار كامل |
| `ملف المُصوِّت غير موجود` | تأكد أن مجلد `weights` فُك كاملًا مع `vocos22.onnx` (57MB) |
| رسائل مربعة/رموز غريبة بدل العربي في الكونسول | لا تؤثر على التوليد؛ أو استخدم Windows Terminal، أو نفّذ `chcp 65001` قبل التشغيل |
| التوليد بطيء جدًا | أغلق البرامج الثقيلة؛ جرّب `--threads 4`؛ أول تشغيل أبطأ دائمًا (تحميل النماذج) ثم يبدأ سريعًا |
| `Successfully installed` لم تظهر | انسخ رسالة الخطأ كاملة — غالبًا الشبكة؛ جرّب أمر الـindex البديل في الخطوة 4 |

## ملاحظات تقنية (للمهتمين)

- كل عمليات torch على المعالج صراحة: `torch.load(map_location='cpu')`
  و`model.to('cpu')` — لا يوجد أي `.cuda()` أو دقة نصفية (amp/half)
  في أي مكان بمسار التوليد.
- المُشكِّل catt_eo والمُصوِّت vocos22 يعملان بـonnxruntime بمزوّد
  `CPUExecutionProvider` فقط.
- المسار الحسابي **مطابق bit-by-bit** لمسار التوليد في نواة التدريب
  (تم التحقق بالموازاة على نفس الـcheckpoint — تفاصيل في PATCHES.md).
- ملفات جمل الاختبار الأصلية (`samples/test_sentences.txt`) هي نفسها
  المستخدمة في نواة التدريب لو أردت مقارنات موسّعة.
