# عينات الاستماع البشري — تدقيق ما قبل الدمج (PR #1)

أزواج WAV «قبل/بعد» لمراجعة **استماع بشري مصري** قبل قرار دمج
`fix/auto-diacritize-egyptian-reference`. هذه هي الخطوة الأخيرة المعلقة في
التدقيق النهائي: كل الفحوصات الآلية تمت، والفصل الأخير في جودة النطق
للبشر.

## البروتوكول (المقارنة الأمينة)

كل زوج ولد **بنفس الأوزان والإعدادات حرفيًا** — الفرق الوحيد بين الملفين
هو نص التشكيل (مخرج `main` مقابل مخرج فرع الإصلاح):

| الإعداد | القيمة |
|---|---|
| checkpoint | `states_cont_180516.pth` (غير معدَّل) |
| speaker | 0 |
| pace | 1.0 |
| emotion | 0 |
| denoise | 0.005 |
| peak_normalize | true |
| sample rate | 22050 Hz، mono، 16-bit |

الكود الصوتي متطابق بين الفرعين — أي فرق تسمعه ناتج عن نص التشكيل فقط،
لا عن تغيير في النموذج أو الأوزان.

## اتفاقية التسمية

- `A{n}_before_main.wav` — الصوت بنص تشكيل **main** (قبل الإصلاح)
- `A{n}_after_fix.wav` — الصوت بنص تشكيل **فرع الإصلاح** (بعد)
- التقريران `audio_integration_report.json` (مسار الفرع الكامل مرحلة
  بمرحلة) و`audio_before_after_report.json` (الأزواج + التوكنات + المدد)
  يوثقان كل حالة؛ المسارات المطلقة داخلهما تشير إلى بيئة التدقيق الأصلية
  والملفات المناظرة موجودة بجوار هذا الملف.
- ملفات `A{n}.wav` الأساسية في بيئة التدقيق كانت مطابقة تمامًا
  (MD5) لـ`A{n}_after_fix.wav` فلم تُرفع مكررة.

## تحذير منهجي صريح

اختلاف التوكنات أو الصوت **ليس بذاته دليلًا على نطق أفضل** — المقارنة
الآلية أثبتت فقط أن الفرع يغيّر المخرجات في المواضع المستهدفة ويحفظ
الباقي. الحسم في «أي النطقين أصح مصريًا» هو مسؤولية المراجع البشري
المصري المؤهل، وهو الغرض من هذه العينات.

## طريقة المراجعة المقترحة

1. سماع بترتيب مخلوط (لا تعرف أي ملف «قبل» وأيه «بعد» إن أمكن) وبسماعات
   داخلية، بصراحة تامة في التسجيل لكل حالة.
2. لكل حالة سجّل حكمًا ثلاثيًا: «بعد أفضل» / «قبل أفضل» / «لا فرق جوهري»
   + ملاحظة نوعية عن الكلمة المحددة (مثل: «هُوَ مسموعة أفضل في السياق»).
3. A4 تحققًا لا حكمًا: إن سمعت فرقًا فاقعًا فيها فبلّغ فورًا — يعني خللًا
   في بروتوكول التوليد نفسه.
4. القرار النهائي للدمج يجمع: نتائج الاستماع هنا + نتائج التدقيق الآلي
   (انظر تقرير التدقيق النهائي) — لا يُبنى على أحدهما منفردًا.
