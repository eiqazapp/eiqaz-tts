# بروتوكول الاستماع المعمّى — التحقق السمعي من إصلاح التشكيل (PR #1)

## الغرض

المقارنة السمعية النهائية قبل قرار دمج فرع `fix/auto-diacritize-egyptian-reference`
في مستودع `eiqazapp/eiqaz-tts`. كل زوج (L0n_A / L0n_B) صُنع من **نفس نموذج
الصوت ونفس المتحدث ونفس الإعدادات حرفيًا** — الفرق الوحيد بين A و B هو
**نسخة كود التشكيل النصي** (نسختان مختلفتان من منطق وضع الحركات على
النص قبل تركيبه). **لا يُفصح هنا أيهما النسخة الأساسية وأيهما الجديدة** —
مفتاح التعيين محفوظ لدى منظم المراجعة ولا يُفتح قبل إتمام الاستماع.

## الملفات

- `L01_A.wav` / `L01_B.wav` … `L08_A.wav` / `L08_B.wav` — ثمانية أزواج،
  كل زوج لجملة واحدة بنسختي التشكيل.
- `evaluation_form.csv` — نموذج التقييم (املأه وأعده لمنظم المراجعة).
- لا تفتح أي ملفات تدقيق أخرى في المستودع (مثل `validation/audit_audio/`)
  قبل إتمام مراجعتك — فهي تكشف الجهات وتُبطل التعمية.

## معلومات تقنية موثقة (بلا كشف الجهات)

| البند | القيمة |
|---|---|
| نموذج الصوت | نفس الـ checkpoint تمامًا في كل الملفات (بصمة git مطابقة) |
| المتحدث / السرعة | speaker=0 / pace=1.0 |
| معدل العينة | 22050 Hz، mono، 16-bit |
| بيئة التوليد | نفس العملية الحسابية والنسخ البرمجية للكود الصوتي |

انتبه: بعض الأزواج قد تبدو **متطابقة تمامًا** — هذا مقصود ضمن تصميم
المراجعة (حالات ضابطة). إن لم تسمع فرقًا فعلًا فاكتب «لا فرق واضح» بصدق؛
الإجابة الصادقة أهم من الإجابة الحاسمة.

## طريقة المراجعة

1. سماعات داخلية (In-Ear) أو سماعات مغلقة، في مكان هادئ، بمستوى صوت
   مريح ثابت طوال الجلسة.
2. لكل حالة: شغّل `L0n_A` ثم `L0n_B` (يمكن الإعادة مرتين أو ثلاثًا —
   لا أكثر حتى لا تتلاشى الانطباعات الأولى).
3. قيّم كل نسخة على المعايير الخمسة (1–5) في `evaluation_form.csv`:
   - **طبيعية النطق المصري**: هل يبدو الكلام لهجة مصرية طبيعية أم مفتعلة؟
   - **صحة الحركات الداخلية**: هل الحركات داخل الكلمات صحيحة للمعنى
     والسياق (وليست فقط «موجودة»)؟
   - **وضوح الكلمات**: هل كل كلمة مسموعة بوضوح بلا بلع أو دمج؟
   - **سلامة نطق الكلمات العامية**: هل الكلمات العامية تُنطق كما ينطقها
     مصري بالفعل (لا تُقرأ قراءة فصحى)؟
   - **أخطاء أو أصوات غريبة**: صف أي خلط، لثغة غريبة، همزات زائدة،
     أصوات مكسورة، أو مقاطع مبتورة — أو اكتب «لا».
4. سجّل **التفضيل**: A / B / لا فرق واضح.
5. في الملاحظات النوعية **اذكر الكلمات المحددة** التي سمعت فيها الفرق
   (مثال: «كلمة X في A مسموعة أنقى») — هذا أهم عمود للتشخيص.

## مقياس التقدير

| الدرجة | المعنى |
|---|---|
| 5 | طبيعي تمامًا كمتكلم مصري |
| 4 | جيد جدًا — ملاحظة واحدة صغيرة |
| 3 | مقبول — ملاحظات واضحة لا تمنع الفهم |
| 2 | ضعيف — يشوش الفهم |
| 1 | مرفوض — نطق خاطئ أو كلام مكسور |

## بيانات المراجع (أضفها أعلى النموذج عند التعبئة)

- الاسم (اختياري) / التاريخ
- هل أنت **ناطق أصلي باللهجة المصرية**؟ (نعم/لا — مطلوب «نعم» للحسم)
- بيئة السماع (سماعات داخلية / مغلقة / مكبر صوت) ومدى الهدوء

## إقرار منهجي

- الفحوص الآلية (توكنات، مدد، تطابق موجي) **لا تحسم جودة النطق** — هي
  أثبتت فقط أن الاختلافات محصورة في الكلمات المستهدفة وأن ما لم يتغير
  نصيًا لم يتغير صوتيًا. الحسم السمعي مسؤولية هذا الاستماع البشري.
- نتائج هذا الاستماع **لم تكتمل بعد** — لا توجد أي أحكام استماع مسجلة
  حتى تعبئة هذا النموذج، ولن تُختلق نتائج بغيابه.
- القرار النهائي للدمج = نتائج هذا النموذج + تقرير التدقيق التقني المرفق
  في المستودع (`validation/listening_review/TECHNICAL_REPORT.md`).
