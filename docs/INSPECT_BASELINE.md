- **السلسلة**: نص → `prepare_text_rich` (تنظيف + علامات {ق}/{ء}/{ج} + تشكيل `catt_eo.onnx` اختياري + طبقة القاف) → `get_tokenizer`→`toks_egy` (`arabic_to_buckwalter` → `fix_qaf` → `buckwalter_to_phonemes` → `phonemes_to_tokens` → `EGY_TOKEN_MAP`) → `MixerTTSModel.infer(x, pace, speaker, emotion=0)` (PyTorch) → mel [B,T,80] → `mel_to_wav` (vocos22.onnx، denoise=0.005) → WAV 22050Hz PCM_16.
- **النموذج الصوتي**: `MixerTTSModel` (FastPitch-style غير تلقائي) — `regulate_len` بـ cumsum+matmul (صديق لـONNX). `net_config` مخزّن داخل checkpoint: `num_tokens=148, padding_idx=0, symbols_embedding_dim=128, n_speakers=16, n_emotions=16, energy_conditioning=False`.
- **المتكلمان**: 0=ذكر (SPEAKER_01)، 1=أنثى (SPEAKER_02). سقف التدريب 160 توكن.
- **المكونات ONNX أصلًا**: `vocos22.onnx` (57MB) + `catt_eo.onnx` (78MB). **المفقود**: النموذج الصوتي MixerTTS بصيغة ONNX — هو هدف التصدير.
