# eiqaz-tts — تحويل النص إلى كلام بالعربية المصرية (NileTTS 4h)

مشروع متكامل لتحويل النص العربي المصري إلى صوت منطوق (TTS)، تم فيه تدريب
نموذج **MixerTTS** من الصفر على بيانات **NileTTS** (متحدثان مصريان: ذكر
وأنثى) بميزانية 4 ساعات على وحدة معالجة رسومات من Kaggle، ثم بناء
**حزمة توليد محلية مستقلة** تعمل على أي جهاز Windows عادي **بالمعالج فقط
(CPU) بدون كارت شاشة، وبدون أي اتصال بالإنترنت أو بـKaggle بعد التركيب**.

## نظرة عامة على المشروع

مرّ المشروع بثلاث مراحل كبيرة، وكل مرحلة موثّقة بالكامل داخل هذا المستودع:

| المرحلة | الوصف | أين تجدها |
|---|---|---|
| **1) التدريب** | تدريب MixerTTS من الصفر على Kaggle GPU خلال ميزانية زمنية 4 ساعات (15,300 ثانية) على 19,721 مقطع تدريب و2,157 مقطع تحقق، بمتحدثين (SPEAKER_01 ذكر + SPEAKER_02 أنثى)، وصولًا إلى نقطة الحفظ النهائية `states_79590.pth` | مجلد `training/` |
| **2) التوليد المحلي** | استخراج مسار التوليد فقط من نواة التدريب وتحويله إلى حزمة مستقلة تعمل على Windows بـCPU فقط، مع كل التبعيات والأوزان مضمّنة — تم اختبارها فعليًا في بيئة نظيفة تحاكي جهاز المستخدم | مجلد `inference/` |
| **3) التشكيل المصري** | خط أنابيب لتشكيل نصوص الداتاست تشكيلًا مصريًا (بدل التشكيل الفصحي الإعرابي التلقائي) عبر LLM مع فحوص آلية صارمة — توقف عند 116/21,880 جملة بسبب حصة API، والمحرك الاقتصادي v5.2 جاهز للاستئناف | مجلد `tashkeel-pipeline/` |

**أهم خصائص حزمة التوليد:**

- سطر واحد يُحوّل النص إلى WAV: `python infer.py --text "..." --out out.wav`
- يعمل على **أي معالج حديث** بسرعة ~2 ثانية للجملة (تم قياسها فعليًا).
- كل الأوزان مضمّنة (المُشكِّل catt_eo بحجم 78MB + المُصوِّت vocos بحجم 59MB).
- لا يحتاج سوى **6 مكتبات** فقط، ونسخة torch الخاصة بـWindows هي CPU تلقائيًا.
- **الـcheckpoint غير مضمّن في المستودع** (لأن ملفاته كبيرة جدًا لـgit) — وهو موجود
  عندك محليًا من مخرجات Kaggle: ضع `states_79590.pth` داخل مجلد
  `inference/checkpoints/` وسيعمل كل شيء (انظر البدء السريع).

## البدء السريع على Windows

> الدليل المفصّل بالصور والتفاصيل وحل المشكلات موجود في
> [`inference/README_INSTALL_WINDOWS.md`](inference/README_INSTALL_WINDOWS.md).
> هذه هي الخلاصة.

### المتطلبات قبل البدء

- Windows 10 أو 11 (**64-bit** — إلزامي).
- **Python 3.12** (نسخة Windows installer 64-bit من python.org).
- حوالي **1.5GB** مساحة حرة على القرص.
- إنترنت **للتركيب مرة واحدة فقط** (~250MB مكتبات). بعدها لا يوجد أي إنترنت.
- **لا تحتاج GPU ولا أي خبرة لينكس إطلاقًا.**

### الخطوات بالترتيب

**1) نزّل المستودع وادخل مجلد الحزمة**

نزّل المستودع كملف ZIP (زر Code الأخضر ← Download ZIP) أو باستخدام git:

```
git clone https://github.com/eiqazapp/eiqaz-tts.git
cd eiqaz-tts\inference
```

(لو فككت الضغط يدويًا، المسار المشابه: `C:\eiqaz-tts\inference` —
يُفضّل مسار بلا مسافات أو حروف عربية.)

**2) ركّب Python 3.12 (لو لم يكن موجودًا)**

من <https://www.python.org/downloads/> — وفي أول شاشة من معالج التركيب
**علّم المربع ✅ "Add python.exe to PATH"** ثم اضغط Install Now.
للتحقق: افتح `cmd` (زر Windows + R ثم اكتب cmd) واكتب:

```
python --version
```

يجب أن يطبع `Python 3.12.x`.

**3) ضع ملف الـcheckpoint الخاص بك**

انسخ ملف **`states_79590.pth`** (من مخرجات نواة التدريب على Kaggle، وهو
موجود عندك محليًا) والصقه في:

```
C:\eiqaz-tts\inference\checkpoints\states_79590.pth
```

(يمكن وضع أكثر من ملف `states_*.pth` — يُختار الأحدث تلقائيًا.)

**4) ركّب المكتبات (مرة واحدة فقط)**

في نافذة موجه الأوامر (cmd):

```
cd /d C:\eiqaz-tts\inference
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

الانتظار المتوقع: 3–10 دقائق. عند ظهور `Successfully installed ...`
انتهى التركيب — **ومن هذه اللحظة لا تحتاج إنترنت إطلاقًا.**

**5) التوليد الأول**

```
python infer.py --checkpoint states_79590.pth --text "السلام عليكم يا صديقي" --out out.wav
```

انتظر ~2 إلى 6 ثوانٍ، ثم افتح `out.wav` واستمع.

**6) اختبار التأكد من سلامة التركيب**

ولّد الجملة المرجعية نفسها التي وُلّد منها الملف المضمّن
`samples\example_output.wav`:

```
python infer.py --text "إِزَّيْك يَا صَاحِبِي، عَامِل إِيهْ دِلْوَقْتِي؟" --out check.wav --vocalize never --speaker 0
```

قارن بالسمع مع `samples\example_output.wav` — يجب أن يكونا **نفس الصوت
تمامًا** (كلاهما من نفس الـcheckpoint ونفس الجملة ونفس المتحدث). هذا دليل
أن التركيب سليم على جهازك.

## الاستخدام اليومي وكل الخيارات

```
python infer.py --help
```

| الخيار | القيم | الشرح |
|---|---|---|
| `--checkpoint` | مسار/اسم ملف | افتراضيًا: أحدث `states_*.pth` في `checkpoints/` |
| `--text` | نص بين علامتي تنصيص | النص مباشرة |
| `--text-file` | مسار ملف | النص من ملف UTF-8 (مريح للعربي في الكونسول) |
| `--out` | مسار | ملف WAV الناتج (افتراضي `out.wav`) |
| `--speaker` | 0 أو 1 | **0 = SPEAKER_01 ذكر** (افتراضي)، **1 = SPEAKER_02 أنثى** |
| `--dialect` | egy أو msa | egy: الترميز المصري (افتراضي)، msa: فصحى |
| `--pace` | رقم | سرعة الكلام: 1.0 طبيعي، أقل = أبطأ وأوضح، أكبر = أسرع |
| `--vocalize` | auto / always / never | auto: يشكّل النص تلقائيًا لو غير مشكول (افتراضي)؛ never: يستخدم تشكيلك كما هو |
| `--denoise` | رقم | تنقية الضوضاء بعد التوليد (افتراضي 0.005) |
| `--threads` | رقم | تقييد عدد أنوية المعالج (لو الجهاز ضعيف) |
| `--verbose` | — | تفاصيل تقنية (عدد التوكنز، التوقيتات) |

**أمثلة جاهزة:**

```
python infer.py --text "دلوقتي هنبدأ الدرس يا عمر." --out dars.wav --speaker 0
python infer.py --text "أنا عايز أعرف إنت عملت إيه النهارده." --out ask.wav --speaker 1 --pace 0.9
python infer.py --text-file magazine_paragraph.txt --out para.wav --speaker 0
python infer.py --text "اَللُّغَةُ الْعَرَبِيَّةُ مِنْ أَكْثَرِ اللُّغَاتِ" --out msa.wav --dialect msa --vocalize never
```

**نصائح مهمة للجودة:**

1. **النص المشكول أفضل دائمًا**: لو عندك تشكيل يدوي جيد، مرّره مع
   `--vocalize never` — سمعته أعلى من التشكيل التلقائي (الفصحي الإعرابي).
2. **قسّم النصوص الطويلة**: النموذج تدرّب على جمل ≤ 160 توكن (~15–20 كلمة).
   السكريبت يحذّرك لو تجاوزت الحد — قسّم الفقرة إلى جمل.
3. **الترقيم يُقص تلقائيًا** (فواصل/علامات/أرقام/إنجليزي) — هذا مقصود
   ومطابق لبيانات التدريب، فلا حاجة لتنظيف يدوي.

## كيف تدرّب النموذج

التدريب تم على Kaggle بوحدة GPU ضمن ميزانية 4 ساعات، عبر نواتين
(Kernels) — كلاهما مضمّن كاملًا في `training/kaggle-kernels/`:

| الملف | الوظيفة |
|---|---|
| `niletts-4h-prep.py` | تجهيز البيانات من داتاست `KickItLikeShika/NileTTS-dataset` (فحص، تنظيف، تقسيم train/val، بناء المجمعات) |
| `niletts-4h-train.py` | التدريب الكامل + التوليد الدوري للعينات + الحفظ الدوري للـcheckpoints + التوليد النهائي |

**ملخص إعدادات التجربة** (كاملة في `training/run-artifacts/run_config.json`):

| البند | القيمة |
|---|---|
| البنية | MixerTTS من الصفر (وصفة train_ms للمؤلف) — 2,869,602 بارامتر |
| الداتاست | KickItLikeShika/NileTTS-dataset (HuggingFace) |
| المتحدثون | SPEAKER_01 (ذكر) + SPEAKER_02 (أنثى) |
| مقاطع التدريب/التحقق | 19,721 / 2,157 |
| الميزانية الزمنية | 15,300 ثانية (~4 ساعات وربع على GPU) |
| حجم الدفعة | 16 |
| المُحسِّن | AdamW بمعدل تعلم 1e-4 (يتناقص حتى 1e-5) |
| النقطة النهائية | `states_79590.pth` (عند الخطوة 79,590) |

وثائق الجلسة الفعلية في `training/run-artifacts/`: منحنى التدريب
(`training_curve.png`)، سجلات الخسائر خطًا بخط (`train_log.csv` و
`val_log.csv`)، سجل الموارد (`resource_log.csv`)، السجل النصي الكامل
(`niletts-4h-train.log`)، وعينات صوتية من مراحل مختلفة
(`samples/egyptian_scratch/` للمقطع المصري عبر التدريب، و
`samples/original_msa_reference/` للمرجع الفصحي، و
`samples/user_eval/` للعينات النهائية للتقييم).

> **ملاحظة عن الـcheckpoints:** ملفات `*.pth` كبيرة الحجم (مئات الميغابايتات)
> ولا تُخزَّن في git. النقطة النهائية `states_79590.pth` موجودة عندك محليًا
> من مخرجات Kaggle وهي كل ما تحتاجه للتوليد.

## خط أنابيب التشكيل المصري

النصوص المصريّة غير المشكولة تُشكَّل عادةً بمُشكِّلات فصحى (مثل catt_eo
المضمّن في الحزمة) فتُطبّق الإعراب الفصحي على لهجة لا تتبع قواعده. لذلك
بُني خط أنابيب لتشكيل النصوص **تشكيلًا مصريًا** عبر استدعاءات LLM مع
**فحوص آلية صارمة** (ثبات الحروف حرفًا بحرف، سقف التوكنز، بوابات جودة)
ودليل تشكيل مصري مكتوب ومعتمد.

**الحالة الحالية** (تفاصيل كاملة في `tashkeel-pipeline/README.md`):

| البند | القيمة |
|---|---|
| إجمالي الجمل المستهدفة | 21,880 |
| المكتملة قبل توقف حصة API | 116 (منها 65 ناجحة fully-passed) |
| المحرك الاقتصادي v5.2 | جاهز ومُتحقق منه جافًا (29/29 اختبارًا) — بانتظار نافذة حصة لاختبار دخان رسمي |
| داتاست جزئي منشور | `ahmedyaseen86/niletts-4h-tashkeel-ai-v1` (خاص، نصوص فقط) |
| بديل محلي مدروس | نموذج `ahmadsy/tashkeel-nano-4p5m` (17MB) — الجدوى مثبتة قياسًا، لم يُنفَّذ أي تدريب |

كل سكربتات المراحل (46 ملفًا: ph1 الفحص، ph2 التحويل، ph3 محرك التشكيل
بإصداراته، ph4 بناء الداتاست، وأدوات القياس) مضمّنة في
`tashkeel-pipeline/scripts/`، وحالة التشغيل الكاملة القابلة للاستئناف في
`tashkeel-pipeline/state/`.

## الضمان والجودة

قبل تسليم حزمة التوليد، تم التحقق منها بثلاث طرق موثّقة
(السكريبت في `validation/pkg_validate.py`):

| الاختبار | النتيجة |
|---|---|
| موازاة التوكنز والـmel وWAV مع كود نواة التدريب الأصلي على نفس الـcheckpoint | **تطابق bit-by-bit** (فرق 0.0، ارتباط 1.000000) |
| موازاة المخرج مع عينة GPU نهائية من نفس الـcheckpoint | تطابق طول كامل (38,400 عينة) وارتباط موجي **1.000** |
| تشغيل كامل في بيئة نظيفة تحاكي جهاز المستخدم (Python نظيف، CPU، بلا أي ملفات Kaggle) | نجح — **1.9 ثانية/جملة**، وأعاد إنتاج المخرج المرجعي بارتباط 1.000000 |

كما وُثّقت كل التعديلات على الكود المضمّن في
[`inference/PATCHES.md`](inference/PATCHES.md) — خمسة تعديلات جراحية فقط،
كلها لجعل استيرادات مسار-التدريب-فقط اختيارية، **دون أي تعديل على بنية
النموذج أو الأوزان أو معادلات الترميز**.

## الاعتمادات والتراخيص

هذا المشروع يقف على أكتاف أعمال الآخرين — شكرًا لأصحابها:

- **NileTTS Dataset** — `KickItLikeShika/NileTTS-dataset` (HuggingFace):
  بيانات التدريب الأساسية للمتحدثين المصريين.
- **MixerTTS** — بنية النموذج (`lib/mixer_repo` كما وردت في حزمة التدريب
  `mixer-tts-scratch-data`).
- **tts_arabic** — مكتبة المعالجة النصية والترميز العربي
  (`lib/tts_arabic`) وتشمل مُشكِّل **CATT** (`catt_eo.onnx`).
- **Vocos** — المُصوِّت الصوتي (`weights/vocos22.onnx`).
- **tashkeel-nano-4p5m** — `ahmadsy/tashkeel-nano-4p5m` (HuggingFace):
